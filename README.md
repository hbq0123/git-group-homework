# 知阅图书管理系统

## 项目简介

知阅图书管理系统是一个基于 Web 的桌面端图书馆管理平台，提供图书借阅、座位预约、空间预订、缴费管理等核心功能。系统采用单页应用（SPA）架构，使用 localStorage 作为前端数据存储方案，支持多用户账户管理、主题切换和数据自动备份。

### 主要功能

- **用户管理**：注册、登录、账户切换、个人资料编辑
- **图书管理**：图书浏览、搜索、借阅/归还、图书信息管理（管理员）
- **座位预约**：自习座位实时预约、楼层切换、日历选择
- **空间预订**：研讨室、静音舱等空间预订
- **缴费管理**：逾期费用、押金管理
- **主题切换**：8 种预设主题 + 自定义颜色主题
- **数据备份**：自动备份、手动导入/导出备份文件
- **密码安全**：SHA-256 加密存储、登录失败锁定机制

## 技术栈

### 前端技术

- **HTML5**：语义化标签、表单验证
- **CSS3**：Flexbox/Grid 布局、CSS 变量、动画效果、响应式设计
- **JavaScript (ES6+)**：原生 JavaScript，无框架依赖
- **Font Awesome 6.4.0**：图标库（CDN 引入）

### 数据存储

- **localStorage**：前端数据持久化（用户信息、图书数据、借阅记录等）
- **MySQL 5.7+**：数据库 Schema 设计（用于未来后端扩展）

### 安全技术

- **SHA-256**：密码哈希加密（Web Crypto API）
- **账户锁定**：5 次登录失败后锁定 3 分钟
- **数据完整性验证**：启动时自动检查和修复数据

## 功能说明

### 用户注册

1. 在登录页面点击"注册"标签
2. 填写必填信息：
   - 姓名
   - 学号/工号（唯一标识）
   - 班级

   - 确认密码
3. 点击"注册"按钮完成注册
4. 注册成功后自动登录

### 登录/登出

**登录：**
1. 输入学号/工号和密码
2. 点击"登录"按钮
3. 登录失败 5 次后账户锁定 3 分钟

**登出：**
1. 点击右上角用户头像
2. 在下拉菜单中选择"退出登录"
3. 返回登录页面

### 图书借阅

1. 在左侧导航栏点击"图书借阅"
2. 使用搜索框或分类筛选查找图书
3. 点击图书卡片查看详情
4. 点击"借阅"按钮确认借阅
5. 借阅成功后在"我的借阅"中查看

### 座位预约

1. 在左侧导航栏点击"座位预约"
2. 选择楼层（1F-3F）
3. 选择日期和时间段
4. 点击空闲座位（绿色）选中
5. 点击"确认预约"完成预约

### 主题切换

1. 点击用户头像进入"个人中心"
2. 在设置列表中选择"主题设置"
3. 点击预设主题卡片切换
4. 或选择"自定义主题"调整颜色
5. 主题设置会自动保存

### 数据备份

**自动备份：**
- 系统默认开启自动备份
- 每 5 分钟自动备份一次
- 页面关闭前自动备份

**手动备份：**
1. 进入"个人中心" → "数据备份"
2. 点击"导出备份"下载 JSON 文件
3. 点击"导入备份"选择 JSON 文件恢复

## 常见问题

### Q: 为什么每次打开都要重新注册？
A: 请确保从固定路径打开 `index.html`，不要从临时目录（如 `.qoder-cn\tmp\`）打开。从临时目录打开会导致 localStorage 数据丢失。

### Q: 主题切换后没有效果？
A: 请清除浏览器缓存后重试。如果问题持续，请按 F12 打开开发者工具查看控制台错误信息。

### Q: 如何恢复默认数据？
A: 打开浏览器开发者工具（F12）→ Application → Local Storage，删除所有以 `lib_` 开头的键，然后刷新页面。

### Q: 数据备份文件在哪里？
A: 数据备份存储在浏览器的 localStorage 中，键名为 `lib_system_backup_snapshot`。导出的备份文件会下载到浏览器的默认下载目录。
